botChat 1.1.7

本次更新由桌面操作通道（macUse）的调用形状与可判定性改造主导：工具面由五降四、find 空结果可判定、骨架裁剪改按字节自适应、新增 activate 动作；同时把 Electron 类应用的 Web 渲染器无障碍接入流程，并优化设置页快捷键键帽的渲染性能。

改进

  • 桌面工具面五降四，wait 退役：wait 是工具面上唯一「失败不影响正确性、只影响效率」的工具，长期不可用却无人发现（本机审计日志中它仅被调用 1 次，failed:INVALID_ARGS，从未真正进入等待循环）。其职责已各有更优归属——动作后的读回验证由 act 的 settle 承担，读取前的静默等待由 observe 的稳定读承担。act 因此成为唯一独占写租约的工具，不再被等待中的后续 act 堵在串行队列头。
  • observe 读取前稳定读：连续观察两次直至快照稳定再返回，让模型拿到的是「已经不再变化」的界面，避免因界面动画/布局未落定而取到中间态。
  • 调用形状优化：收紧工具入参与出帧形状，降低单次桌面往返的 IPC 开销与上下文占用。
  • 桌面纪律点名 observe：运行纪律中显式要求模型先观察后动作，并补上工具面静态门禁，防止工具面漂移。

修复

  • find 空结果不再二义：此前裸空数组同时表达「不存在 / 未展开 / id 失效」三种处境，模型无从判断该重搜还是该钻取。现在返回体同时给出命中集与覆盖集（coverage.visitedNodeCount 与 scopeNodeCount 用来判定是否「看全」），truncatedRoots 提供可直接抄用的钻取入口，下一步分类统一复用 LocatorNextStep；nth 越界改为显式失败而非返回空。
  • find 搜不到自动补深：浅层无命中时自动往下补一层深度，不再把入口清单甩回给模型自行钻取。
  • 骨架裁剪改按字节预算自适应：不再用固定层数截断，改为按字节预算裁剪，可寻址元素优先保留，被丢弃的元素计数上报，不静默丢信息。
  • 截断点不可寻址时向上取祖先：截断边界若落在不可寻址节点上，改用最近的祖先作为钻取入口，避免给出打不开的定位。
  • 深度不再被档位吞掉：深度默认值提到 24，档位不再覆盖显式深度；截断时错误信息自证所需与实际值。
  • pressKey 前台前提补齐（新增 activate 动作）：pressKey 硬性要求目标 app 在前台，但此前没有任何动作能建立这个前提——act(press) 的五步链全是元素级 AXAction，没有一步会调 NSRunningApplication.activate，实盘表现为返回 delivered_verified 而 affectsFrontmostApp 为 false（声称成功、事实未发生）。新增 activate 动作用把目标 app 提到前台，验证口径以 frontmostApplication 读回为准；pressKey 前台失败时 hint 指向 activate。
  • Electron/Chromium 类应用的 Web 无障碍默认不建：这类 app 的 Web AX 子树默认不构建（窗口只剩红黄绿三个按钮），observe 现在取窗口树前按窗口拉起并回可判定四态（enabled / disabled / unavailable / notApplicable），不再把「原生 App 不适用」与「Web 树没建」合并为同一种失败；判据取 webAreaNodes > 0 && textNodes > 0，不以 AXError 返回值判成败。

性能

  • 设置页快捷键键帽逐颗渲染并改查表贴图：键帽拆出独立 KeyCap 组件按颗渲染，贴图改为查表复用，两道阴影留在同一个贴图层内一次画完，显著降低按键列表的绘制开销。
