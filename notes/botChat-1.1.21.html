botChat 1.1.21

本次主线：代码引用从「尾注」改为正文里可点的行锚链接，引用与正文不再两套说法；插件现在能在时间线上产出自己的行卡片；界面控件的外观与对比度做了一轮收口。

代码引用：正文即真相

引用一段代码后，它以 markdown 行锚链接的形式写进正文，输入条的行内胶囊、发送后气泡下方的引用行都由这段字符派生，不再有第二份记录。

  • 气泡下方的引用胶囊可点开对应文件预览。路径过长从中间截断，行号后缀始终可见；多枚引用自动换行、不横向滚动，任何一枚都点得到。
  • 删除就是删字符：输入条上方点 ×、或退格，都等于删掉正文里那段链接，不存在「界面删了正文还在」。
  • 发送时不再在正文末尾追加旧式的「（引用代码 path 行 12-30）」说明。你看到的就是发出去的，也是模型读到的。

插件：可以在时间线上产出自己的行

插件新增了「每轮收尾自动产生一行」的声明能力，配合轮次起止 hook 采集本轮事实，行内可用预制节点渲染或调用原生面板。

  • 新增工作区快照接口：插件在 hook 里取本轮变更文件清单时不能指定路径，读哪个仓库由宿主按会话决定，因此不存在借插件绕开路径授权的口子。
  • 修复：插件行此前在时间线上会显示成一条「Update Todo List / 0 todos」的错误行，数据也永远显示「本轮没有变更记录」。
  • 修复：单个插件启用后无需重启应用即可收到 hook 事件，此前要等下次启动才生效，且失败时没有任何提示。

界面：控件收口与对比度

  • 按钮语义与重量拆成两个独立维度（危险操作不再只能表达成「很重的按钮」），中量档改用系统原生玻璃材质，极小图标钮并入同一套组件。
  • 按钮与标签在同档尺寸上原本有 8pt 错位，现已对齐；标签改为「语义 × 强调 × 尺寸」组合，强调档统一用白字。
  • 修正一批对比度不达标项：浅色 tokyo-night 主题与深色 github 主题的强调文字此前低于 4.5:1，现全部达标。
  • 加载指示改为分档外观，并修正了描边越界导致的拥挤感。
  • 全应用单行 / 密码 / 多行输入框换成同一套组件，输入区外观一致。
  • 工具栏动作回到系统原生样式——此前套用玻璃底会与工具栏自身的材质叠出双层边框。
