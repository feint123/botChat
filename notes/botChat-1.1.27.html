botChat 1.1.27

本次主线：启动与安装成本大幅下降，轨迹视图与时间线的滚动稳定性收敛到单一虚拟表格载体；插件面板获得内嵌网页能力，同时插件挂载面由六面收敛为五面。

新增与改进

  • 启动明显变快：内置服务启动 12.7s → 2.5s（构建后首次启动约 4.2s）。服务端启动对账从全表水合改为水位线增量判定，provider 与 MCP 等重模块改为按需导入；客户端就绪探测退避上限从 2s 收到 0.25s，服务端已就绪时不再白等一拍。
  • 安装包变小：安装包改为无源码字节码分发，dmg 从 71.3MB 降到 59.1MB；包内导入再省一半时间（2.29s → 1.15s）。
  • 插件面板可以内嵌网页了：面板源码放行 WebKit，插件能把自己的远端页面挂进面板（可出网，不能读取本地文件）。附 examples.browser 样例插件。
  • 插件拿得到真实工作目录：${workspace} 改为按当前会话工作目录展开，state 新增 workingDir（当前会话工作目录的绝对路径），插件不必再自己拼绝对路径。清单与插件代码零改动。
  • 长任务的子代理进度不再中段断流：进度发言从「一次性额度」改为节律保活，任意静默不超过 250s（3 分钟 3 条、30 分钟 11 条、60 分钟 18 条），长任务尾部不再长时间静默。
  • 轨迹视图收敛到单一虚拟表格载体，长会话下滚动更跟手。

修复

  • 修复输入条上方 250pt 内「看得见、点不着」：底部留白改由滚动内容内的尾部占位行承担，该区域内的文字双击、拖选与按钮点击恢复可用，贴底留白仍在。
  • 修复轨迹视图真机上下滚动来回抖动：窗口起点按块量化、偏移判等后再回调、窗口内容总高固定，抖动闭环被切断。
  • 修复多个子代理同轮发言互相吞行：进度行的幂等键补入 taskId，同一轮里各子代理的进度不再静默丢失。
  • 修复插件行水合风暴造成的掉帧：行出现不再无条件触发整轮重拉，失败走有界退避，快照重拉做在途合并，服务端渲染单飞。
  • 修复插件面板状态水合与快照的会话串台。
  • 修复气泡渲染崩溃：正文里残缺的 ]( 不再构造倒置区间。

需要动作

  • 插件挂载面由六面收敛为五面：client.row 下线，声明它的插件不再生效，需迁移到 panel / window / composer.accessory / sidebar.section / settings.section 五个面。既有插件行按普通文本呈现，不空白、不崩溃。
  • 技能引用的正文载体从自定义指令 :::cmd 换成标准 markdown 链接；历史消息里的 :::cmd 字面量按普通文本显示，不再可点。技能引用本身仍可点开对应的 SKILL.md。
