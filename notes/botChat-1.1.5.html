botChat 1.1.5

本次更新把「客户端控件」统一到全新的 Paper 组件体系，并让模型选择从「换主 Agent」扩展为 四角色分发（主 / 池 / 命名 / 读图）；同时修复了工具取消后倒计时不消失的顽疾。

新增

  • Paper 系列基础组件：新增 PaperIconButton、PaperMenuPicker、PaperPopoverSurface、PaperPressStyle、PaperFieldBox、PaperGlassField、PaperSearchChip，重构 PaperSearchField 与 PanelHeaderIconButton，PaperTheme 补齐对应设计令牌。全站控件的按压反馈、边框、弹层质感自此同源。
  • 模型角色分发：composer 模型浮层的列表行显示该模型已占用的角色徽章，底部新增角色摘要条（主 / 池 / 命名 / 读图），点击行按当前目标角色分发写入。主 Agent 仍走「会话级 + 全局」双写并关闭浮层；池 / 命名 / 读图只走全局通道且浮层保持打开，便于连续配置。
  • Provider 设置看板：新增 ProviderListView、ProviderListEditor、ProviderListModelRowView、ProviderRolePickerPopover、ProviderRoleSummaryBar、ProviderSlotSections 与 ProviderRoleChip，按角色分栏管理模型提供方；顶部只读角色总览条点选即可横滚定位到对应列。
  • Todo 看板创建流程：看板支持直接新建待办，不再需要绕道命令行或其它入口。

改进

  • 控件全面迁移至 Paper 体系：聊天输入区、设置窗口、工作区文件面板、DesignMode 画布、Todo 看板与提交面板的按钮 / 菜单 / 字段 / 弹层统一换用 Paper 组件，消除各处自绘控件在高度、圆角、按压态上的漂移。
  • 角色口径收敛：角色槽位的读取与写入一律转发 ProviderAssignmentStore，不新增第二条写链路，避免配置双写不一致。

修复

  • 工具执行中取消/中断后倒计时冻结、停止无效：服务端不为在飞工具补结果帧，客户端又用失效字段当收口门闩，两层缺陷叠加导致工具行永久停在「执行中」——秒数冻结、停止入口随 run 隐藏、点了也没用。
  • 服务端新增 tool_ledger 按 run 记账「已发 START、未收到结果」的调用，tool_backfill 作为补帧唯一实现（落库与出帧同点、逐条 fail-soft）。
  • 新增三码 TOOL_ABORTED_BY_RUN_TERMINATION / DECLINED_BY_USER / ORPHANED_BY_RESTART，与工具自身失败族分立，不污染超时与取消率指标。
  • 取消分支与 finally 各结清一次，保证四个出口不漏；ask_user 建中断与 delegate 暂缓这两条「有意不落结果」的分支主动脱账，避免误补。
  • 启动时由 run_reconcile 清理跨重启遗留的无结果调用。
