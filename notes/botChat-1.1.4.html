botChat 1.1.4

本次更新聚焦 Goal 执行器台账 与 Todo 看板 两条主线的打通，并补齐「待答问题」的作答闭环。

新增

  • Goal 执行器台账链路：新增 goal_actions / delivery / facts 三张台账与 goal_deliver 工具，子 Agent 的交付申报、动作记录与事实快照统一落库，供时间线回放与复盘。
  • Todo 看板绑定会话工作区：看板支持按会话工作区归类，新增「未分类」视角与归属提示，跨会话待办一眼可辨。
  • 待答问题答复闭环：pending_question 增加独立作答端点 POST /api/todos/{id}/answer，「需要你拍板」的问题可在卡片上直接作答；答复以独立段落注入执行 prompt，不影响 prompt 改写审计。
  • 待办彻底删除：支持 DELETE /api/todos/{id}，看板提供删除动作。

改进

  • Todo 面板视觉与结构统一：头部复用 PanelHeaderBar 消除双条厚重头部，动作条拆分为 TodoRowActionBar 并收敛到 InlineCapsule 组件；字号阶梯集中到 PaperTheme.FontSize，空态/失败态复用 WorkspaceChangesEmptyState 贴纸样式。
  • 原因行默认摘要展示：原始报文折叠为可选复制，噪声不再抢占版面。
  • 提交方案页签视觉统一，复用贮藏与更改列表既有组件；提交方案改为手动生成并收敛到方案页签。

修复

  • 会话可见 kind 白名单纳入 goal，并同步守住删除级联。
  • ManagerKindBadge 兼容 goal 与历史 manager 会话标识。
  • LiveCapture 分辨率档位与输出尺寸改为同源统一口径，消除档位与实际输出不一致。
  • MacUse 通道握手归属连接与会话接管语义修复。
  • AI 分组编号化与自适应预算超时导致的频繁降级修复。
