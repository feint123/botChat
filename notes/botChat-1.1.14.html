botChat 1.1.14

本次两支主线：插件体系从「能跑」变成「能看见、能装、能开关」；工具分层补上第二段调用入口——被 tool_search 发现的工具，终于能在同一轮里真正被调用。

新增

  • 插件体系 P0+P1：插件代码跑在独立宿主子进程，主进程只保留装配层与工具表；清单 v2 协议、沙箱与审计、三轨工具注册（本地 / MCP / 插件）、启用态落库与重启恢复。扫描与登记零代码执行，第三方插件需显式授权后才真正运行。
  • 设置 → 插件页：三分区列表（已启用 / 未启用 / 已移除登记残留）与插件详情——版本、信任档与降级原因、root 与包路径、能力、激活事件、三态授权矩阵、工具、逐条诊断；支持安装（选本机目录）、启停、逐项授权、删除、清登记、宿主重启、解除拉黑。
  • tool_invoke 代理工具：与 tool_search 成对注册，模型可凭名字在同一轮内调用此前只被发现的工具；未知工具名最多给出 3 个近似候选，单条失败不中断同批调用。

改进

  • 工具检索面口径修正：从「tier 等于 extended」改为「本次未进入 tools 数组」，被 core_limit 截断的核心工具重新可达，不再出现「能搜到、调不了」。
  • 统一执行路径：执行器抽出 execute_resolved，代理调用复用同一条路径——预检、超时、patch 透传、并发额度、tool_cancel 全部一致，不重复抢占并发额度。
  • 插件安装与删除边界：安装只收本机绝对目录，先复制到 .staging 再原子落位；删除一律移入 .trash/ 而非直接删，授权保留。

修复

  • 插件启用偶发 database is locked：同一请求内两个会话写同一 SQLite 文件，启用路由改为先提交再接线；接线失败日志带异常首行，诊断文案改指「重启宿主」，避免用户循环踩同一个坑。
  • 插件设置页报错态撑破布局：内容理想高度曾达 1142pt，把顶部横幅与列表顶出可视区，根部容器改为钉住尺寸。

其他

  • 内部测试基建：工具目录基线比对改为关系式不变量、退役 129KB 冻结快照——改坏映射必红、只改工具描述必绿；生产代码零改动。
  • 迁移提示：扩展状态表迁移 n7a8b9c0d1e2 随包发布；若用 SKIP_MIGRATIONS=1 启动嵌入式服务，需自行执行 alembic upgrade head。
  • 新增三份跨块文字选取与「引用聊天文字」调研文档，零代码改动。
