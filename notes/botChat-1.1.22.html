botChat 1.1.22

本次主线：新增「聊天模式」，让会话区回归对话本身，工具调用与思考收进轨迹；每位发言人身边带一枚活动胶囊，实时显示「正在做什么」；插件界面收敛为原生面板一种形态。

新增

  • 设置 →「通用 → 会话区域」新增「聊天模式」开关（默认关闭）：打开后会话区只保留对话本身，工具调用、思考与执行步骤收进轨迹，决策卡与故障提示照常显示。
  • 聊天模式下，每位发言人所在段落尾部会有一枚活动胶囊，实时显示其正在做什么（如「正在运行 bash，12s」），动作结束后短暂转为「已完成」。
  • 助手在正文还没吐出来时会先说一句接话应一声；长时间没有可见进展时会主动播报一次进度，播报带〔摘要〕标注表示是转述而不是原话。
  • 子助手的进展会以单独一行转述出现（同样标〔摘要〕），长时间执行不再看起来像卡住。
  • Command Code 服务商补齐品牌图标与余额查询：用量页可看到额度百分比与下次重置时间，5 小时窗口与剩余额度收在一行摘要里。

改进

  • 插件界面只保留原生面板一种呈现形态：仍只提供旧式预制节点界面的插件，其界面不再显示，面板位置给出说明与入口——该插件需要更新。
  • 插件面板显示不出来时按原因给出对应操作：去设置里同意或启用、复制缺失编译工具链的安装命令、重试、或让助手修（把编译错误摘要填进输入条）。
  • 聊天模式下发言人头像放大，助手固定使用一枚身份贴纸、子助手使用分配给它的贴纸与名字，谁在说话一眼可辨。
  • 助手自己的接话与正文使用同样式（同字号、同气泡、同样解析），不再是一行更小更弱的提示。

修复

  • 修复「发言人认错人」：助手自己的发言曾被标成「子助手」，且同一条消息的身份会随长度翻转；现在归属稳定，真子助手的长正文也不再被画成助手。
  • 修复历史消息上一直挂着「思考中」：活动胶囊只出现在最新一轮，不会停留在旧气泡上。
  • 修复活动胶囊的三处问题：计时不走秒、停留在「思考中」时没有胶囊、配色过于显眼（改为更中性的一档）。
  • 修复「回到底部」胶囊在会话进行中已贴底时反而不出现：进行中常驻，随时能看到最新动作。
  • 修复提问卡中多行输入框被压扁、占位文字压到边框并与上一行重叠；空间不足时改为卡片内滚动，选项与提交按钮不再被挤压。
  • 修复插件面板取色不完整导致的部分配色异常（浅色主题下会出现黑底输入框、黑字按钮），面板配色现在完整跟随主题的浅/深外观。
