界面示意 · 非实时

CAPABILITIES

过程可见，结果可收。

主 Agent 与子 Agent 的消息出现在同一条时间线上。谁在干什么、卡在哪里，都看得见，也都能追问。

任务编排

主 Agent 拆解需求，现场合成子 Agent 并行执行，完成后汇聚成一份结果。

群聊式时间线

主 Agent 与子 Agent 的消息、工具调用同流展示，可取消、可续跑。

任务预确认卡

关键提交前弹一张结构化确认卡，确认后再执行，不用重写提示词。

多列工作区

可拖拽分栏，相邻列可锁定成组整体移动，3 个布局预设一键切换。

桌面操作

经独立 mac_use 委派变体派出，看窗口、点按钮、输文本。桌面操作有动作分级。

工具与 MCP

bash 合并登录 shell 环境（服务端优先 + PATH 并集），文件读写与 MCP 池接入。

定时与 Skill

到点自动发起一轮运行；项目 Skill 按需装载，会话记忆可跨会话回捞。

设计系统库

设计系统库76 套

内置 76 套设计 token（Claude / Vercel / Stripe / Spotify 风格）供设计任务取用。

WORKFLOW

三步，从一句话到一份结果。

父会话不阻塞等待，子 Agent 结果自动投递回来。

01

说需求

在左侧输入你要什么，不用拆步骤，不用写流水线配置。

02

拆解并合成

主 Agent 拆成 3–4 个子任务，现场合成子 Agent 并行跑，状态实时可见。

03

汇聚交付

子结果自动投递、汇聚成一份完整答复，可继续追问或续跑。

INSTALL

三行命令，装好即用。

内置 Python / FastAPI 服务随 botChat.app 一起启动，无需自己跑后端。

terminal — zsh
$ brew tap feint123/tap
$ brew trust feint123/tap
$ brew install --cask botchat

系统要求：macOS 26 及以上（建议 26.1+）· Apple Silicon（arm64）· 也可以直接下载 botChat-1.0.dmg 安装。

当前版本未经 Apple 公证，首次打开可能被 Gatekeeper 拦截；可用 --no-quarantine 安装，或执行 sudo xattr -dr com.apple.quarantine /Applications/botChat.app 解除。
